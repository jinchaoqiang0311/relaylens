🌱 免费公开端点

无需注册,浏览器直接访问即可看到 JSON。适合做自己的看板、机器人推送、学术分析。

GET /v1/ranking 免费
全站实测榜单。默认返回综合榜,可通过 scene 参数取任一场景分榜。
参数必填说明
scene可选场景分榜:all(默认)/ code / office / ecom / drama / image / biz / risk
model可选按模型系列过滤:claude / gpt / gemini / deepseek / glm
fields可选逗号分隔的字段白名单,如 name,score,dev,avail(减小响应体积)
响应示例(截断)

{
  "updated": "2026-09-29T09:41:00+08:00",
  "version": "v2026.09.29-114",
  "license": "CC-BY-4.0",

    {
      "name": "RelayAPI",
      "score": { "code": 96, "all": 94 },
      "dev": 0.0,          // 扣费偏差 %,7天均值

  ]
}
GET /v1/prices 免费
模型比价:各站各模型的输入/输出/缓存单价、充值比例与到手价(已折算)。价格随 6 小时批次同步更新。
参数必填说明
model可选指定模型 ID,如 claude-opus-5、gpt-5.6-sol;缺省返回全部
honest_only可选true 时只返回缓存计费诚实(dev≤1% 且公示缓存价)的报价
// GET /v1/prices?model=claude-opus-5
{
  "model": "claude-opus-5",
  "officialRef": { "in": 42, "out": 210 },  // ¥/M 官方参考
  "offers": [
    {
      "site": "RelayAPI",
      "in": 18, "out": 88,
      "cacheRead": 1.8,  "cacheWrite": 22.5,
      "ratio": 1.0,      // 人民币元 / 1 美元额度 的充值比例(实测)
      "effectiveIn": 18.0, // 到手输入价 = in × ratio
      "cacheBilling": "honest"  // honest | partial | none
    }
  ]
}

参数必填说明

⚡ Pro 端点(需 Bearer Key)

面向需要深度历史与实时性的场景:自动化交易/监控、研究报告、审计留档。

GET /v1/batches PRO
历史检测批次:365 天内任意站点的逐批次数据,含逐轮对账明细。这是"账单级实测"的原始层。
参数必填说明
site必填站点名(与榜单 name 一致)
since / until可选ISO 8601 时间范围,最长 365 天,单次最多返回 500 批次
rounds可选true 时展开 10 轮逐轮明细(token 用量/应扣/实扣/耗时)
# 带 Key 请求
curl -H "Authorization: Bearer sk-rl-..." \
     "https://relaylens.example/api/v1/batches?site=RelayAPI&since=2026-09-01&rounds=true"
POST /v1/webhooks PRO
变更告警订阅:站点标红/摘牌、单周涨价>15%、连续失败、黑名单新增等事件实时推送到你的 Webhook。推送体含事件类型、站点、触发批次号与时间戳,5 秒超时重试 3 次。
// 你的 Webhook 会收到的推送体
{
  "event": "site.flagged",        // flagged | cleared | price_surge | outage | blacklist
  "site": "Orbelis",
  "batch": "RL-EV-0927-058",
  "reason": "连续5批次扣费偏差>4%",
  "at": "2026-09-27T14:20:00+08:00"
}
GET /v1/receipts/{batchId} PRO
原始证据包:指定批次的面板流水存档(截图 + 结构化 JSON)、API 原始 Response、对账计算过程。用于审计留档或争议复核——每个存档编号(RL-RC-*)都可以在这里拿到原始文件。

🛠️ 快速接入示例

📡 场景一:充值前自动风控。你的机器人/工作流在用户发起充值前,调 GET /v1/blacklist 和 /v1/ranking?fields=name,risk 做一次校验,黑名单或高风险站直接拦截。
📈 场景二:自建看板。定时拉 /v1/ranking 存入本地时序库,对比历史分数变化,发现"分数突降"比看静态榜单更早。

const res = await fetch("https://relaylens.example/api/v1/ranking?scene=code");
const { sites, updated, version } = await res.json();

// 置信度过滤:只采信样本充足的站
const trusted = sites.filter(s => s.batches >= 12);
