阶段二 · 受理后需要什么

1
API 端点(base_url)
OpenAI 兼容格式,用于探针接入

      
2
按分组各一个测试 Key
一个 API Key 只能绑一个分组 —— 你声明了几个待测分组,就需要提供几个对应分组的测试 token,否则我们只能测到一个分组、分数口径就不成立。Key 仅通过安全通道提交,明文存放在与代码隔离的密钥文件,永不入库、永不公开

开票 / 对公信息(选填)
