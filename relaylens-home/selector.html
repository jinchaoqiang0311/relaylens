这个工具不做什么

1. 不做流量转发。它只给建议,不代理你的请求,因此不存在托管你 Key 的风险 —— 我们也不因此收站方的转发费用。

2. 不评价"哪个模型更强"。我们没有跑过能力基准(LMSYS / SWE-bench 类),所以模型由你自己定,我们只回答"这个模型在哪家站买最靠谱划算"。任何声称能替你判断模型智力的选型工具,你都该多问一句它拿什么测的。

3. 不覆盖未实测的站与分组。一个 API Key 只能绑定一个分组,所以我们的数据只代表该站被实测的那个分组;同一站其他分组(尤其特价分组)价格与稳定性可能完全不同,结果页会明确标注这一点。

数据是时点数据:渠道会换、倍率会调、号池会枯竭。充值前建议用工具箱自测跑一次你自己的 Key,并用榜单核对最近审计日期。
