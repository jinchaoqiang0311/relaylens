常见问题

API 中转站扣费偏差多少算正常?
计费系统四舍五入与汇率折算会带来 ±0.5% 以内的正常误差(我们实测到的最短单笔因整数取整,偏差可达 2.86%,量级越小越明显)。我们以 1% 为红线:偏差 >1% 的站点进入标红复核队列,人工判定后移出推荐榜;连续多笔同向偏差判定「计费虚标」进黑名单流程。每站的偏差率与逐笔明细在实测详情页可查。
Claude Code 用什么中转站不掉包?
编程场景请认准三个指标:①模型指纹检测通过(返回内容特征与官方直连对比相似度 ≥85%);②缓存命中真实性(写代码场景缓存命中应占输入 50% 以上,不认缓存意味着成本翻倍);③SSE 流式完整率。首页「编程专用」卡片已按这三项预筛选,直达结果。
如何验证缓存是否真实生效?
最简单的方法:连续发两轮相同的长 Prompt,检查第二轮响应的 usage 字段中 prompt_tokens_cached 是否显著上升、扣费是否按缓存价(官方约输入价的 10%)计算。我们每站每批次都做 10 轮缓存命中率统计,数据在实测详情页公开;你也可以用「自测工具箱」的 API Key 自测 3 分钟跑完。
你们的推荐位收费吗?排名能买吗?
排名不能买。推荐位先过实测门槛(不通过的站不接推广),再按 综合得分 → 佣金率 → 活动有效期 依次排序,卡片均标注「含推广链接」;佣金率只在服务端参与排序,不下发到页面。另有两条硬红线:实测不通过的站不接推广、进入黑名单的站永久解除合作。目前没有合格合作站时,那个区域就空着并写明原因 —— 我们不会摆一个假优惠码上去。全部实测数据与复现脚本开源,欢迎逐条验证。
