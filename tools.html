问模型「你是谁」能防掉包吗?

不能。中转站可注入系统提示词让模型谎报身份。本工具因此不测「你叫什么」,而是测可验证的结构:Token 计量是否随输入线性变化、SSE 是否真流式、返回的 model 字段与请求是否一致。判定掉包需要官方基线对照,那部分由我们服务端做。

Token 虚标怎么发现?

发 3 段长度已知的唯一中文文本(每次随机打散,防缓存),读 usage.prompt_tokens 做线性拟合。斜率应约等于 1 token/汉字;若截距远大于 0,或短文本也报出数千 cached,说明存在固定注入脚手架。我们实测两家站注入约 +4858 / +3959 tok/请求(2026-09-30 口径)。

假流式是什么?

协议层看着像流式(SSE、分块),实际把上游完整回复缓冲后一次下发,首字要等全文生成完。判定必须用长输出(约 200-300 字):看内容块是逐 token 到达还是一次性倾泻 —— 短答案(两三个字)单块到齐是真流式的常态,不能作为判据。后果是 Cursor / Claude Code 的逐字渲染失效、无法中途打断。部分站还呈现混合行为:同一模型,有的请求流式、有的被缓冲(多渠道路由所致),工具会如实标注。

检测会暴露我的数据吗?

探针文本是随机生成的公开测试语料,不含你的业务数据与任何个人信息;请求从你浏览器直连目标站,RelayLens 不经手。回传报告是可选动作,且不含 Key。
